## Repo Micro-Skills

- **Shell and paths**: the cwd resets between Bash calls, so start each command with `cd /c/Users/micah/Downloads/scripture-memory-app && …`. There is no `src/hooks/`: state hooks live in `src/state/` and pure logic in `src/lib/`, so `ls src` before guessing a path. `react-native-svg/src/web/` files are `.ts`, not `.tsx`. A scratchpad script that imports repo code by a long `../../..` path fails in esbuild, so keep such scripts inside the repo or use absolute paths.
- **Writing code: use Write/Edit, not shell**: `cat > file <<'EOF'`, `node -e "…"` and `python - <<EOF` mangled backslashes and regexes and failed with "unexpected EOF" on quotes, and bash ran backticks and `${…}` as command substitution. Failed heredocs created no file (`src/lib/mapWalk.ts`), so `ls` a new file before building on it. If you must script a replace, assert the anchor count first (`syncedQueueJsonRef.current = new Map();` appears twice in `useAppState.ts`), then read `git diff` for duplicated blocks (a double insert gave TS2451 "Cannot redeclare" in `RecallPanel.tsx`). Many files are CRLF on disk, so normalize newlines in scripted edits.
- **Check labels**: a bare `'` inside a single-quoted `check('…chapter's weekday', …)` label breaks esbuild ("Expected `)`"). Use double quotes or a template literal. To add a check, copy `scripts/run-passages-check.cjs` to `scripts/run-<name>-check.cjs` and add `check:<name>` to `package.json`.
- **Verify with**: `npx tsc --noEmit -p . && for c in layout queue calendar stages outbox appstate; do npm run -s check:$c 2>&1 | tail -1; done`. Run tsc right after a type change, since a new type needs its import (`ReviewGrade` in `useAppState.ts` gave TS2304) and its callers updated. After you intentionally add or remove AppState fields, run `npm run -s check:appstate -- --update` and commit `scripts/appstate-keys.snapshot.txt`.
- **Baseline before blame**: `check:layout` has 3 pre-existing `[fixed-height]` errors (e.g. `ActivityHeatmap.tsx:159`, `LoadingScreen.tsx:31`), and `check:maplayout` ("every star is placed") and `check:milestones` also failed unedited.
